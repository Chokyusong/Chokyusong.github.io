이야기
01무엇인가
프로그램 아이디어를 질문으로 구체화해 설계 문서를 만들고, 사람이 승인하면 그 범위 안에서 AI 개발 에이전트가 작업을 나눠 구현, 테스트, 검증을 반복하는 로컬 개발 도구입니다.
02안전하게
설계를 승인하기 전에는 파일을 고칠 권한이 없습니다. 승인 뒤에도 기본은 읽기 전용이고, 코드는 따로 떼어 낸 Git 작업 공간에서만 바뀝니다. push, PR, 배포, 결제는 승인에 포함되지 않아 자동으로 하지 않습니다.
03끝나는 조건
설계에 적은 완료 조건을 모두 테스트로 확인했을 때만 최종 결과를 만들고, 그 뒤 사람이 마지막으로 확인합니다.
