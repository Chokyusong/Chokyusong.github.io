큰손탐지기수집 서버

라이브 방송 수백 곳의 후원 데이터를 실시간으로 모아 집계하는 24시간 서버입니다. 1,350만 건으로 부하 시험을 해 병목을 고쳐 대시보드 응답을 수십 배 줄였습니다.

시험용으로 만든 3달 치 기록으로 병목을 찾아 고쳤습니다. 막대 길이는 걸린 시간입니다.

이야기
01목적
AutoLed와 조회 화면에 쓸 방송 후원 통계를 직접 모으는 서버가 필요했습니다.
02만든 것
공개 라이브 방송 수백 곳의 후원 기록을 모아 저장하고 집계합니다. 방송 목록은 1분마다 새로 확인합니다. 관리자만 보는 대시보드에서 기간별 방송 순위와 집계를 봅니다.
03성능
시험용으로 만든 3달 치 기록 1,350만 건으로 부하 시험을 해 병목을 고쳤습니다. 실제로는 하루 7만여 건을 1vCPU, 1GB 서버 한 대로 받습니다.

운영 숫자

7만여 건하루에 받는 후원 기록
1vCPU · 1GB서버 한 대로 운영
약 20초재부팅 시험에서 모두 복구
84개코드가 바뀌면 도는 자동 테스트

멈추지 않게, 잃지 않게

  • 서비스는 부팅하면 저절로 켜지고, 5분마다 멈춤을 감시합니다.
  • 매일 암호화 백업을 받고, 매달 백업을 실제로 풀어 건수를 맞춰 보는 복원 연습을 자동으로 돌립니다.
  • 바깥 감시는 GitHub Actions가 30분마다 합니다.
  • 요청한 사람의 기록은 지우고 더 모으지 않는 수집 거부 목록을 둡니다.
