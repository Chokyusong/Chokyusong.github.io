운영하며 챙기는 것

  • 관리자 여러 명과 역할, OTP, 모든 쓰기에 감사 기록을 남깁니다.
  • 앱이 받는 토큰은 서버 키로 서명합니다.
  • 커밋마다 별도 폴더로 배포하고 버전 태그를 달아, 문제가 생기면 이전 버전으로 바로 돌아갑니다.
  • 지나치게 잦은 접속은 자동으로 막고, 서버가 멈추면 다시 켜지게 둡니다.
